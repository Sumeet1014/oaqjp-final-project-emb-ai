# Emotion Detector

## Project Overview
This project detects emotions expressed in text using IBM Watson Natural Language Processing services.

## Features
- Detects emotions in user-provided text.
- Identifies anger, disgust, fear, joy, and sadness.
- Returns the detected emotions and dominant emotion.
- Provides a Flask web interface for testing.

## Technologies Used
- Python
- Flask
- Requests
- IBM Watson NLP Emotion Detection API
- Unit Testing
- Pylint

Install the required dependencies, configure the emotion detection service, and run the Flask application using Python.
